# Инструкция для пользователя

Это про то, как пользоваться уже запущенным ассистентом. Про установку и деплой — в
[DEPLOY.md](DEPLOY.md), это для разработчика/администратора, не для повседневной работы.

**Важно сразу:** теперь есть визуальная панель с кнопками в браузере — самый простой способ
смотреть статистику, вакансии и черновики, настраивать фильтры и включать/выключать опрос
без единой команды в терминале. Плюс Telegram-бот (для этого всё уже готово, ничего делать
не нужно). Команды в терминале (curl) ниже оставлены как запасной способ — на случай, если
панель по какой-то причине недоступна, или если вам просто удобнее так.

## Панель в браузере — с этого стоит начать

Откройте в браузере:

```
http://ВАШ_СЕРВЕР:8077/
```

(замените `ВАШ_СЕРВЕР` на настоящий адрес/IP сервера — так же, как и в ссылках ниже).

На панели одной страницей собрано всё:

- **Вверху** — жив ли ассистент и активен ли сейчас опрос вакансий (два цветных индикатора,
  обновляются сами каждые ~15 секунд).
- **Управление опросом** — кнопки «⏸ Остановить опрос» и «▶ Возобновить опрос» (то же самое,
  что кнопка аварийной остановки ниже, только без терминала), плюс видно число неудачных
  циклов подряд, если оно больше нуля.
- **Статистика** — сколько вакансий на какой стадии, сколько потрачено на ИИ сегодня и всего.
- **Поиски** — адреса поисков, по которым ассистент ходит за вакансиями. Настройте
  фильтры прямо на сайте площадки, скопируйте URL из адресной строки и вставьте
  сюда. Галочка «Активен» позволяет временно выключить поиск, не удаляя его.
  Раньше эти адреса лежали в файле настроек на сервере — теперь править их можно
  прямо отсюда, перезапуск не нужен.
- **Фильтры** — список уже настроенных фильтров с кнопками «Изменить»/«Удалить», и форма ниже
  для создания нового или правки существующего — поля и значения выбираются из выпадающих
  списков, вручную печатать JSON не нужно.
- **Вакансии** — таблица со всеми увиденными вакансиями (можно отфильтровать по статусу).
  Клик по строке разворачивает подробности: полное описание, информация о заказчике и
  черновик отклика — его можно скопировать одной кнопкой («📋 Скопировать») и, после того как
  вставили и отправили его на Upwork вручную, отметить кнопкой «✅ Отклик отправлен» — так же,
  как кнопкой в Telegram.

Если страница не открывается — скорее всего, порт `8077` закрыт файрволом сервера снаружи
(см. ниже, в разделе про ссылки). Тогда работают команды curl из этого же файла.

## Что происходит само

Раз в 6–14 минут (интервал плавает специально) ассистент сам:
1. Заходит на Upwork под вашим аккаунтом и смотрит новые вакансии по сохранённому поиску.
2. Отсеивает по фильтрам (если вы их настроили — см. ниже; если нет, пропускает все).
3. Оценивает оставшиеся по шкале 0–10, насколько подходит вам.
4. Для вакансий с оценкой выше порога — пишет черновик отклика и присылает в Telegram.

Больше ничего сам не делает — отклик никогда не отправляется автоматически, это всегда
ваше решение и ваше действие на сайте.

## Сообщение в Telegram

Приходит два сообщения на каждую подходящую вакансию:

1. **Карточка вакансии**: заголовок, ссылка, бюджет/ставка, требования, информация о
   заказчике, оценка ИИ и почему.
2. **Черновик отклика** с кнопкой **«✅ Отклик отправлен»**.

Что делать: открыть вакансию по ссылке из первого сообщения → скопировать текст черновика
из второго → вставить на Upwork и отправить самим → вернуться в Telegram и нажать кнопку
«✅ Отклик отправлен» (просто чтобы ассистент знал, что по этой вакансии вы уже
отреагировали — на сам Upwork это никак не влияет).

## Тревожные сообщения (⚠️)

Ассистент пишет в Telegram, если что-то пошло не так — не молчит и не делает вид, что всё
нормально. Частые случаи:

| Сообщение | Что это значит | Что делать |
|---|---|---|
| `Скоринг вакансии ... упал` | ИИ не смог оценить эту вакансию (сбой сети/API) | Обычно ничего — следующая вакансия обработается нормально. Повторяется часто — напишите разработчику |
| `Генерация отклика ... упала: ... profile.md не найден` | Не настроен файл с вашим опытом для генерации откликов | Напишите разработчику — нужно один раз загрузить `data/profile.md` на сервер |
| `Дневной бюджет ... исчерпан` | Потрачен дневной лимит на ИИ (сумма из `OPENROUTER_DAILY_BUDGET_USD`) | Ничего делать не нужно — с завтрашнего дня лимит обнулится. Хотите повысить лимит — скажите разработчику |
| `Page.goto: Timeout ...` (при заходе на Upwork) | Сайт Upwork не открылся за отведённое время (например, заблокировал IP сервера) | Если разово — ничего. Если повторяется — см. ниже про «3 подряд неудачных цикла» |
| `N подряд неудачных циклов опроса — остановлено` | Ассистент 3 раза подряд не смог собрать вакансии и **сам себя выключил**, чтобы не долбить Upwork вхолостую | Нужно ваше действие — см. «Кнопка аварийной остановки» ниже |

## Запасной способ: через ссылки и команды в терминале

Всё, что описано в этом разделе и ниже, уже доступно на панели выше в удобном виде. Читайте
дальше, только если панель недоступна или вам привычнее так.

### Как посмотреть статистику и список вакансий

Каждая из ссылок ниже открывается прямо в браузере (просто вставить в адресную строку) —
покажет текст в машинном формате (JSON), это нормально, читать можно и так. Замените
`ВАШ_СЕРВЕР` на настоящий адрес/IP сервера.

```
http://ВАШ_СЕРВЕР:8077/health              — жив ли ассистент
http://ВАШ_СЕРВЕР:8077/stats               — сколько вакансий обработано, сколько потрачено на ИИ сегодня
http://ВАШ_СЕРВЕР:8077/jobs                — список всех увиденных вакансий
http://ВАШ_СЕРВЕР:8077/jobs/2096947778304263398          — одна вакансия по её номеру (id виден в /jobs)
http://ВАШ_СЕРВЕР:8077/jobs/2096947778304263398/draft     — черновик отклика по этой вакансии
http://ВАШ_СЕРВЕР:8077/filters             — список ваших фильтров
```

Если ссылка не открывается (браузер долго думает и не отвечает) — скорее всего, порт `8077`
закрыт файрволом сервера снаружи. Это сделано специально ради безопасности (см. DEPLOY.md,
раздел «Безопасность») — спросите у разработчика, как получить доступ (например, через
SSH-туннель).

### Кнопка аварийной остановки

Если увидели в Telegram «N подряд неудачных циклов — остановлено» — ассистент встал и сам
не включится, это специально, чтобы не тратить деньги и не палиться на Upwork вхолостую.

**Остановить вручную** (например, если сами заметили что-то подозрительное и не хотите
ждать):
```
curl -X POST http://ВАШ_СЕРВЕР:8077/admin/pause
```

**Включить обратно** (после того как причина устранена — например, вам помогли с
проблемой на сервере):
```
curl -X POST http://ВАШ_СЕРВЕР:8077/admin/resume
```

Обе команды выполняются в терминале (на Windows — через Git Bash или PowerShell, на
Mac/Linux — обычный терминал), не в браузере — команда `curl -X POST` из браузерной
адресной строки не сработает.

**Проверить, включён ли сейчас ассистент:**
```
http://ВАШ_СЕРВЕР:8077/admin/status
```
`"scheduled": true` — работает, ждёт следующего цикла. `"circuit_open": true` — стоит,
нужен `resume`.

### Как настроить фильтры

Фильтр — это набор правил вида «поле» + «сравнение» + «значение». Вакансия должна
подойти под правило, чтобы попасть к вам в Telegram (иначе тихо отсеивается).

Правила настраиваются командой в терминале (не в браузере — форма создания/изменения
фильтра требует отправки данных, а не просто открытия ссылки):

```bash
curl -X PUT http://ВАШ_СЕРВЕР:8077/filters/мой_фильтр \
  -H "Content-Type: application/json" \
  -d '{
    "match_mode": "all",
    "is_active": true,
    "rules": [
      {"field": "budget_amount", "operator": "gte", "value": 300},
      {"field": "client_payment_verified", "operator": "eq", "value": true},
      {"field": "title", "operator": "not_contains", "value": "wordpress"}
    ]
  }'
```

Замените `мой_фильтр` на любое имя (латиницей, без пробелов) — так вы сможете обновить
именно этот пресет позже, отправив ту же команду с новыми правилами вместо старых.

`"match_mode"`: `"all"` — вакансия должна подойти под ВСЕ правила сразу; `"any"` —
достаточно ХОТЯ БЫ ОДНОГО. `"is_active": false` временно отключает пресет, не удаляя его.

### Доступные поля (`"field"`)

| Поле | Что означает | Тип значения |
|---|---|---|
| `job_type` | Тип оплаты | `"fixed"` или `"hourly"` |
| `budget_amount` | Бюджет фикс-цены ($) | число |
| `hourly_min_rate` / `hourly_max_rate` | Почасовая ставка ($/час) | число |
| `experience_level` | Уровень опыта | `"entry"`, `"intermediate"`, `"expert"` |
| `client_payment_verified` | Способ оплаты заказчика подтверждён | `true`/`false` |
| `client_total_spend` | Сколько всего потратил заказчик ($) | число |
| `client_avg_rating` | Средний рейтинг заказчика | число 0–5 |
| `client_reviews_count` | Сколько у заказчика отзывов | число |
| `entry_cost` | Стоимость отклика в Connects | число (пока всегда 0 — см. известные ограничения в README) |
| `competition` | Число уже поданных откликов | `"less_than_5"`, `"5_to_10"`, `"10_to_15"`, `"15_to_20"`, `"20_to_50"`, `"50_plus"` |
| `title` / `description` | Заголовок / текст вакансии | текст |
| `skills` | Список навыков вакансии | текст или список текстов |

### Доступные сравнения (`"operator"`)

| Оператор | Значит |
|---|---|
| `eq` / `ne` | равно / не равно |
| `gt` / `gte` / `lt` / `lte` | больше / больше-или-равно / меньше / меньше-или-равно |
| `in` / `not_in` | значение входит / не входит в список (`"value"` — список) |
| `contains` / `not_contains` | текст содержит / не содержит слово |
| `contains_any` / `contains_all` | среди навыков есть хотя бы один / есть все из списка (`"value"` — список) |

### Примеры

Только вакансии с фикс-ценой от $500, заказчик с подтверждённой оплатой:
```json
{"match_mode": "all", "is_active": true, "rules": [
  {"field": "job_type", "operator": "eq", "value": "fixed"},
  {"field": "budget_amount", "operator": "gte", "value": 500},
  {"field": "client_payment_verified", "operator": "eq", "value": true}
]}
```

Исключить вакансии про WordPress или с рейтингом заказчика ниже 4.5:
```json
{"match_mode": "all", "is_active": true, "rules": [
  {"field": "title", "operator": "not_contains", "value": "wordpress"},
  {"field": "client_avg_rating", "operator": "gte", "value": 4.5}
]}
```

**Удалить фильтр:**
```bash
curl -X DELETE http://ВАШ_СЕРВЕР:8077/filters/мой_фильтр
```

**Посмотреть, что сейчас настроено:**
```
http://ВАШ_СЕРВЕР:8077/filters
```

## Как обновить «резюме» для генерации откликов

Файл `data/profile.md` на сервере — это то, что ИИ использует, чтобы писать отклики от
вашего имени (опыт, стек, тон). Изменить его текст самостоятельно можно, но заливка нового
файла на сервер — через разработчика (см. DEPLOY.md, шаг 3) либо попросите добавить туда
более простой способ редактирования, если это нужно часто.

## Сколько это стоит

Скоринг вакансий (дешёвая модель) идёт постоянно, генерация отклика (дорогая модель) —
только для вакансий выше порога. Дневной лимит расходов настроен заранее
(`OPENROUTER_DAILY_BUDGET_USD` в `.env`, по умолчанию $2) — при превышении генерация
черновиков останавливается до следующего дня, скоринг продолжает работать. Текущие траты —
на странице `/stats` (см. выше).
